# guif

guif は、キーボード操作を中心にした Windows 用のファイラーです。フォルダーの一覧とツリーの表示、ファイルの操作(コピー、切り取り、貼り付け、名前の変更、削除、新規作成)、検索、訪問履歴とジャンプリスト、ZIP の圧縮と展開、テキスト・Markdown・画像を見るためのビューア、登録したアプリで開く機能、設定ファイル(`config.toml`)を開いて書き方を確かめる機能を備えています。

この版は 0.3.0 で、最初の配布です。

## 対象環境

- Windows 10 または Windows 11(64 ビット版)
- 管理者権限は不要です(現在のユーザーだけにインストールされます)。
- 画面の表示には Microsoft Edge WebView2 ランタイムを使います。インストールされていない PC では、インストーラーがインターネットから取得して導入します。

## インストール

1. 配布されたインストーラー `guif_0.3.0_x64-setup.exe` を実行します。
2. 画面の案内に従って進めます。インストール先は、既定では `%LOCALAPPDATA%\guif` です。
3. インストールが終わったら、スタートメニューの「guif」から起動します。

### SmartScreen の警告が出たとき

このインストーラーにはコード署名がありません。そのため、インターネットから入手したインストーラーを実行すると、Windows の SmartScreen が「Windows によって PC が保護されました」という警告を出すことがあります。

警告が出た場合は、次の手順で進めます。

1. 警告の画面で「詳細情報」を選びます。
2. 表示される「実行」を選びます。

入手元が分かっているインストーラーであることを確かめてから実行してください。

## アンインストール

Windows の「設定」の「アプリ」(Windows 11 では「インストールされているアプリ」、Windows 10 では「アプリと機能」)から「guif」をアンインストールします。

アンインストールの画面に「アプリのデータを削除する」というチェックがあります。既定ではチェックが外れており、そのままアンインストールすると設定と履歴は残ります。guif を入れ直したときは、残した設定が戻ります。設定も消したいときは、チェックを入れてからアンインストールしてください。
