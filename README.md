# ReflexFiles

ReflexFiles は、キーボード操作を中心にした Windows 用のファイラーです。フォルダーの一覧とツリーの表示、ファイルの操作(コピー、切り取り、貼り付け、名前の変更、削除、新規作成)、検索、訪問履歴とジャンプリスト、ZIP の圧縮と展開、テキスト・Markdown・画像を見るためのビューアを備えています。

この版は 0.3.0 で、最初の配布です。旧製品 ReflexFIles(インストーラーの版 0.2.0)の後継ですが、旧製品を置き換えるものであり、旧製品の設定は引き継がれません。

## 対象環境

- Windows 10 または Windows 11(64 ビット版)
- 管理者権限は不要です(現在のユーザーだけにインストールされます)。
- 画面の表示には Microsoft Edge WebView2 ランタイムを使います。インストールされていない PC では、インストーラーがインターネットから取得して導入します。

## インストール

1. 配布されたインストーラー `ReflexFiles_0.3.0_x64-setup.exe` を実行します。
2. 画面の案内に従って進めます。インストール先は、既定では `%LOCALAPPDATA%\ReflexFiles` です。
3. インストールが終わったら、スタートメニューの「ReflexFiles」から起動します。

### SmartScreen の警告が出たとき

このインストーラーにはコード署名がありません。そのため、インターネットから入手したインストーラーを実行すると、Windows の SmartScreen が「Windows によって PC が保護されました」という警告を出すことがあります。

警告が出た場合は、次の手順で進めます。

1. 警告の画面で「詳細情報」を選びます。
2. 表示される「実行」を選びます。

入手元が分かっているインストーラーであることを確かめてから実行してください。

## 旧製品 ReflexFIles からの置き換え

ReflexFiles は旧製品 ReflexFIles(インストーラーの版 0.2.0)を置き換えるものです。旧製品がインストールされている PC では、先に旧製品をアンインストールしてください。旧製品が残っていると、インストーラーは案内を表示してインストールを中止します。何も変更しません。

1. Windows の「設定」を開き、「アプリ」を選びます。Windows 11 では「インストールされているアプリ」、Windows 10 では「アプリと機能」です。
2. 一覧から「ReflexFIles」を選び、アンインストールします。
3. もう一度 ReflexFiles のインストーラーを実行します。

旧製品の設定は引き継がれません。旧製品の設定フォルダー(`%APPDATA%ReflexFIles`)は、旧製品のアンインストーラーの設定によっては削除されることがありますが、既定では残ります。これは ReflexFiles のインストール先 `%LOCALAPPDATA%ReflexFiles` とは別のフォルダーです。詳しくは [ユーザーマニュアル](docs/user_manual.md) を参照してください。

### 新製品を入れた後に旧製品のインストーラーを実行しない

ReflexFiles をインストールした後で、旧製品のインストーラーを実行しないでください。旧製品のインストーラーは、ReflexFiles のインストール情報を旧製品のものとして扱うことがあり、その結果は保証できません。

## アンインストール

Windows の「設定」の「アプリ」(Windows 11 では「インストールされているアプリ」、Windows 10 では「アプリと機能」)から「ReflexFiles」をアンインストールします。

アンインストールの画面に「アプリのデータを削除する」というチェックがあります。既定ではチェックが外れており、そのままアンインストールすると設定と履歴は残ります。ReflexFiles を入れ直したときは、残した設定が戻ります。設定も消したいときは、チェックを入れてからアンインストールしてください。
