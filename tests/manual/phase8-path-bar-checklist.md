# Phase 8 パスバー・ドライブ切替 手動確認チェックリスト

- 対象仕様: SPEC-0300-0016(第2版)、SPEC-0300-0009(第9版)、SPEC-0300-0010(第12版)、SPEC-0300-0012(第4版)、SPEC-0300-0013(第5版)
- 根拠: `docs/architecture/proposals/SPEC-0200-0001.md` §3.7(§3.7.10優先)
- 位置づけ: 自動テストでは確認できない項目(実ドライブ・ネットワーク・IME・WebView2)の消し込み用。
- 2026-10-01 オーケストレーターが実Tauriで確認済み: Ctrl+Lで全選択、Tab補完、Enterでの移動、存在しないパス・ファイルパスのエラー表示、`/`と`..`の正規化、パスバーで↓、`F:`入力とツリーからのドライブ切替、Ctrl+Lで検索バーを閉じる、編集中のクリックで編集破棄。

- 結果: `OK` / `NG` / `N/A`
