# 外部アプリ起動 手動確認チェックリスト

- 対象仕様: SPEC-0300-0021(第1版、承認後の追補を含む)
- 根拠: SPEC-0300-0021 R-1587・AC-1550・AC-1551、`docs/architecture/proposals/SPEC-0200-0001.md` §3.16.11
- 位置づけ: 既定の4つの登録が実際のアプリを開くことの目視確認。自動の E2E はテスト用の実行ファイル(`rf_launch_probe`)だけを起動し、利用者のアプリは起動しない(SPEC-0300-0021 R-1585)。
- 進め方:
  - 確認者が実アプリを手で操作する。CDP で登録のキーやメニューを操作しない(R-1585 の 1)。
  - アプリは `npx tauri dev`(テスト用の範囲の指定なし)で起動し、普段の設定フォルダーのまま使う。`config.toml` に `external_apps` が無いことを確かめてから行う(既定の4つが有効になる)。
  - 確認用のフォルダーは作業用フォルダーの `ext-check`(下の各項目)。開いたアプリのウィンドウは確認の後に閉じる。
  - 利用者の普段の作業を妨げない時間に行う(R-1587)。
- 作成日: 2026-10-17

## 凡例

- 結果: `OK` / `NG` / `N/A` / `SKIP`(未実施は空欄)
