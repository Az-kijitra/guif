# Phase 11 OS クリップボード連携 手動確認チェックリスト

- 対象仕様: SPEC-0300-0011(第8版)、SPEC-0300-0018(第2版)、SPEC-0400-0001(第4版)
- 根拠: `docs/architecture/proposals/SPEC-0200-0001.md` §3.10(§3.10.17優先)
- 位置づけ: 実際のウィンドウ操作や他アプリとの往復など、E2E では確かめられない項目の消し込み用。
- 注意: これらの確認は実際の OS クリップボードと実ファイルを使います。大切なファイルではなく、確認用に作ったファイルで行ってください。

## 凡例

- 結果: `OK` / `NG` / `N/A`
