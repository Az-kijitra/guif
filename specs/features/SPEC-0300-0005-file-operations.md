## 1. 仕様

- **[R-01] ファイル/ディレクトリのコピーを提供する。**
- **[R-02] ファイル/ディレクトリの移動を提供する。**
- **[R-03] ファイル/ディレクトリの削除を提供する。**
- **[R-04] ファイル/ディレクトリのリネームを提供する。**
- **[R-05] ファイル/ディレクトリの新規作成を提供する。**
- **[R-06] テスト上の優先度を他機能より高く設定しない。** 破壊的操作を特に優先してカバレッジを確保する方針(要件ドラフト §4.1 解釈候補B)は人間レビューで不採用となった。本機能も SPEC-0400-0001 の「MVP機能全般に均等」方針に従う。
