## 1. 仕様

- **[R-01] 部分一致(substring)による検索を提供する。**
- **[R-02] 正規表現(regex)による検索を提供する。**

## 2. 既存実装の参照点(ISS-0013解消済み・2026-09-22: 機能単位でのロジック移植を許容。参照専用ではない)

既存調査 1.1-3 の記録:
- フロントエンド: `page_search.ts`, `components/SearchBar.svelte`, `effects/search.ts`
- バックエンド: 既存調査では「クライアント側処理と見られ、対応する専用バックエンドコマンドは見当たらない」と記録されている。

注記: 上記は既存調査時のHEAD(`new-feature-experiment`)基準(→ ISS-0003)。検索処理をフロントエンド/バックエンドのどちらに置くかは新プロダクトのアーキテクチャ設計工程で決定してよい(既存の配置に拘束されない)。

## 3. 本仕様では確定しない事項(→ ISS-0006)

- 検索対象範囲(カレントディレクトリのみ / 再帰 / ファイル内容検索の有無)
- 大文字小文字の区別、インクリメンタル検索の有無、結果の提示方法
- 正規表現の方言・不正パターン入力時の挙動
