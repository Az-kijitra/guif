## 1. 仕様

- **[R-01] 既存guif(`main`)のREADME記載の基本7機能を全て維持する。** 対象は下表の7機能であり、いずれも新プロダクトのMVPに含める。
- **[R-02] 7機能はスコープ削減の対象としない。** 「無駄な機能をそぎ落とす」(SPEC-0100-0001 R-01)の対象は SPEC-0100-0005 に列挙したスコープ外機能であり、本7機能は削減対象に含まれない。
- **[R-03] 機能の維持は「利用者から見た振る舞いの維持」を意味する。** 既存実装のコード構造・内部設計を維持する意味ではない(SPEC-0100-0002 R-02 と整合)。
- **[R-04] 7機能すべてを均等にテスト対象とする。** SPEC-0400-0001 のカバレッジ方針に従う。
