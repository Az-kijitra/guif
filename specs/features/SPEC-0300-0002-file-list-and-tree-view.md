## 1. 仕様

- **[R-01] 多カラム形式のファイル一覧表示を提供する。**
- **[R-02] ディレクトリ構造のツリービュー表示を提供する。**
- **[R-03] デュアルペイン(2つのファイル一覧ペインの並置、F3)は実装しない。** スコープ外(SPEC-0100-0005 R-05)。【ISS-0016解消済み・発注者確認 2026-09-22: 採用】【ISS-0024解消済み・2026-09-22: 「単一ペイン構成」という表現がR-02のツリービュー表示と用語上衝突して読めたため、SPEC-0300-0009 R-80の表現に合わせて文言を修正(ツリーパネルはファイル一覧ペインとして数えない、という解釈を文言レベルで明確化)】
