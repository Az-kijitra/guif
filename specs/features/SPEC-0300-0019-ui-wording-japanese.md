## 0. 位置づけと表記

- 本仕様は、メインウィンドウとビューアウィンドウに表示する文言(表示する文字列、ボタンの文字、状態メッセージ、ダイアログの文、アクセシブルネーム〈`aria-label` 等〉)の言語と用語を定める。振る舞い・レイアウト・色・キー操作は変えない。
- 各機能仕様が個別の文言を定めている場合も、**言語と用語(§3 の用語表)は本仕様を正本とする**。各機能仕様の文言は、本仕様の新しい文言に合わせて新版で改める(§8)。各機能仕様が条文・受入基準の中で項目名を引用している箇所(例: SPEC-0300-0018 の「カット」)は、新版の読み替えの注記で本仕様の文言に読み替える。
- **仕様書の中の機能名・用語(例: 「訪問履歴」「ZIP 作成」「カット」)は変えない。** 本仕様が変えるのは画面に出る文言だけである。
- 表記:
  - **【確定 #n】** = 発注者決定 2026-10-08(ISS-0207 の #n)。変更不可。
  - **【確定 #6・導出】** = オーケストレーターが同じ方針から導いた判断(ISS-0207 の #6)。異論があれば人間が判断する。
  - **【確定 T-nn】** = 起票時の spec-writer の【提案 T-nn】を、2026-10-08 に発注者が決定したもの(§7、ISS-0208)。変更不可。
  - **【main】** = 旧製品 ReflexFiles の `main` ブランチ(`a62954e`)の日本語訳(`STRINGS.ja`)をそのまま用いる。`main:<行>` の行番号は en / ja の順。
  - **【導出】** = 確定事項・承認済み仕様から spec-writer が導いた帰結。
- **2つの `main` の区別【レビュー m-2】**: 「旧製品の `main`」は ReflexFiles リポジトリの `main`(`a62954e`)、「本リポジトリ」は本プロダクト(`C:\Users\toshi\git\project`)の `main`(`f4e4dcf`)を指す。§4 の「場所」の行番号は本リポジトリのもので、参考である。

## 1. 適用範囲

対象:
- メインウィンドウとビューアウィンドウの、利用者に見える文言とアクセシブルネーム
- 起動時・操作時の状態メッセージ、ダイアログの題名・本文・ボタン、ステータスバーの常設項目、右クリックメニューの項目名と無効の理由
- 文書の言語属性(`lang`)
- 文言の置き場所の方針(R-1201。集め方の設計は設計工程)

対象外:
- 言語の切替・翻訳の仕組み(【確定 #1】。設けない。将来の候補は SPEC-0900-0001 §2.5)
- 仕様書・設計文書・ソースコードのコメント・テストの題名の言語
- ユーザーマニュアル(SPEC-0500-0001。マニュアルが画面の文言を引用するときは本仕様の文言に合わせる。R-1210)
- ファイル名・パス・ファイルの中身など、利用者のデータ
