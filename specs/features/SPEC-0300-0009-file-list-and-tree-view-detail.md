## 10. 受入基準

本節はチェック可能な受入項目である。Phase 1 の完了判定に用いる。

**SPEC-0300-0010 との役割分担(ISS-0025 解消、2026-09-22)**: 本仕様の受入基準は「アクションが発火したときの**表示・選択・フォーカスの結果**」のみを検証する。「特定のキーを押すと当該アクションが発火する」ことの検証は SPEC-0300-0010 を正本とし、本仕様では持たない。初版で重複していた項目は、対応する SPEC-0300-0010 の AC への参照に置き換えた(AC番号は追跡性のため欠番にせず維持する)。
