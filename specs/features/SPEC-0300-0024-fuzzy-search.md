## 0. 位置づけと記述規約

- 本仕様の条文は、2026-10-31 時点の実装の振る舞いを規範として書いたものである。発注者の承認により確定する。
- 条項番号は R-2400 以降、受入基準は AC-2400 以降とする。
- 検証区分: [単体] = vitest / Rust の単体テスト。[CDP] = 実アプリを WebView2 の CDP で操作する E2E(`app/e2e/`。SPEC-0400-0001 に従う)。[静的] = ソースの走査。[手動] = 実機で人が操作して確かめる。

## 1. 適用範囲・用語

- 「ファジー検索の画面」= `fuzzy_find_file` で開く、入力欄と結果の一覧を持つ画面(`FuzzySearchModal.svelte`)。
- 「検索の起点」= 画面を開いた時点のファイル一覧の現在のフォルダー(`fileListState.currentPath`)。
- 「相対パス」= 検索の起点から見た項目のパスで、区切りを `/` にしたもの(例: `src/lib/main.rs`)。
- 「結果」= バックエンドが返す項目の並び。各項目はフルパス(`path`)、相対パス(`relativePath`)、名前(`name`)、フォルダーかどうか(`isDir`)、一致した文字の位置(`matchIndices`)、点数(`score`)を持つ(`FuzzyMatchItem`)。
- 対象外: ビューアウィンドウ、一覧の絞り込み(SPEC-0300-0012)、ファイルの中身の検索。

## 2. 開く

- **[R-2400] 操作 ID `fuzzy_find_file`(既定キー `Ctrl+P` / `Ctrl+F`。SPEC-0300-0010 §4.2 #36)で、ファジー検索の画面を開く。** キーの割当は `input_keymap_custom` で変えられる(SPEC-0300-0010 R-30)。
  - キーでの発火の条件は他のアクションと同じディスパッチによる(SPEC-0300-0010 R-12)。ファイル一覧とツリーのどちらにフォーカスがあっても開く(ファイル操作ではないため SPEC-0300-0010 R-15-1 の抑止を受けない)。検索入力欄にフォーカスがある間(同 R-14-2)、パスバーの編集中(同 R-14-4)、オーバーレイ(ダイアログ・履歴一覧・並び替えメニュー・右クリックメニュー)の表示中(同 R-13)、メニューバーがアクティブな間(同 R-14-5-2)は、キーでは開かない。
- **[R-2401] メニューバーの「移動」の「ファイル検索…」(SPEC-0300-0020 R-1310、文言 SPEC-0300-0019 W-C3)でも開く。** 項目は常に有効で、併記は `fuzzy_find_file` の割当の先頭(既定 `Ctrl+P`)。
- **[R-2402] 開くときは、表示中の右クリックメニューを閉じ、アクティブなメニューバーを非アクティブにしてから開く。**
- **[R-2403] 開くたびに、検索の起点をその時点の現在のフォルダーとし、入力欄を空、結果を空、選択位置を先頭にして、空の入力で検索を1回始める(R-2431)。** 前回の入力・結果は残さない。
- **[R-2404] 開いた後、入力欄にキーボードフォーカスを移す。**

## 3. 画面

- **[R-2410] 画面は、メインウィンドウ全体を覆う背面(`--ui-backdrop`)の上に、横幅 620px(ウィンドウの幅の 92% を上限)、上端をウィンドウの高さの 10% の位置に置いた枠(背景 `--ui-surface`、枠 1px `--ui-border-active`、角丸 4px、影 `--ui-shadow-2`)として表示する。** 枠の中は上から入力欄の帯と結果の一覧である。文字のフォントと大きさは画面のフォント(SPEC-0300-0023 R-1752)を受け継ぐ。
- **[R-2411] 入力欄の帯は、左に検索の印 `🔍`、入力欄、検索中(R-2434)だけ右に印 `⏳` を置く。** 入力欄の枠は無く、帯の背景は `--ui-bg`、下に区切り線(`--ui-border`)を引く。
- **[R-2412] 入力欄のプレースホルダーは `ファイルを検索… (↑↓で選択、Enterで移動、Escで閉じる)`(SPEC-0300-0019 W-C4)とする。**
- **[R-2413] 結果が0件のときは、一覧の位置に、検索中なら `検索中…`(W-C5)、検索が終わっていれば `一致するファイルはありません`(W-C6)を中央寄せで表示する(文字色 `--ui-border-inactive`)。** 結果が1件以上あるときは、新しい検索の間も前の結果を表示したままとし、検索中は R-2411 の `⏳` だけを出す。
- **[R-2414] 結果の各行は、左から種類のアイコン、名前、親のフォルダーの相対パスを置く。** アイコンは SPEC-0300-0023 R-1780-1 の記号(フォルダーは閉じたフォルダーの記号。`aria-hidden="true"`)。親のフォルダーの相対パス(相対パスの最後の `/` より前)は行の右側に右寄せで小さく(0.9em、`--ui-border-inactive`)置き、収まらないときは `…` で切り、`title` に相対パス全体を入れる。検索の起点の直下の項目には親のフォルダーの相対パスを置かない。
- **[R-2415] 名前の中の、照合で一致した文字(R-2432)を強調する(文字色 `--ui-border-active`、太字、下線)。** 一致した位置のうち名前の部分(相対パスの中で名前が最後に現れる位置から後)だけを強調し、親のフォルダーの部分で一致した文字は強調しない。
- **[R-2416] 選択中の行は背景 `--ui-hover`、文字 `--ui-cursor-fg` で示し、一覧の見える範囲に入るようにスクロールする。** 一覧の高さは最大 380px で、超える分は縦にスクロールする。
- **[R-2417] 画面の要素は、枠が `role="dialog"`・`aria-modal="true"`、一覧が `role="listbox"`、各行が `role="option"`・`aria-selected`(選択中の行だけ真)を持つ。** 枠の `aria-label` は `ファイル検索`(SPEC-0300-0019 R-1206 のとおり日本語)。

## 4. キー・マウス操作

- **[R-2420] 画面の表示中のキーは、入力欄の keydown だけで処理する。**
  1. `ArrowDown`、または `Ctrl` を押しながら `n`: 選択を1つ下へ。末尾の次は先頭へ回り込む。
  2. `ArrowUp`、または `Ctrl` を押しながら `p`: 選択を1つ上へ。先頭の前は末尾へ回り込む。
  3. `Enter`: 選択中の項目があれば、それを選ぶ(§6)。無ければ何もしない。
  4. `Escape`: 画面を閉じる(R-2423)。
  5. 1〜4 のキーは既定動作を抑止する。それ以外のキーは入力欄の既定動作(文字の入力・削除等)に任せる。
  - キーの判定はキーマップを使わない固定のもので、`input_keymap_custom` で変えられない。
  - 結果が0件のときの 1・2 は何もしない。
  - IME の変換中(`isComposing`、または `keyCode` 229)のキーは処理せず、IME に任せる(変換の確定の Enter・取消の Escape で項目を選んだり画面を閉じたりしない)。
- **[R-2421] 表示中は、アプリのグローバルなキー処理(SPEC-0300-0010 R-10〜R-17)を、先取りの `Ctrl+Q`(終了)・`Ctrl+,`(設定ファイルを開く)を除いて行わない(SPEC-0300-0010 R-14-6)。** `Ctrl+Q` / `Ctrl+,` は他のオーバーレイの表示中と同じく働く。メニューバーのキー・キーマップのアクションは働かない。
- **[R-2422] マウス: 結果の行のクリックで、その項目を選ぶ(§6)。枠の外(背面)のクリックで画面を閉じる(R-2423)。枠の中の行以外のクリックでは何もしない。** マウスを行の上に乗せても選択は動かない。
- **[R-2423] 閉じるときは、入力・結果・選択位置を消し、待っている検索を取り消し、検索中の結果は捨てる(R-2434)。** Escape・背面のクリックで閉じたときは、他のオーバーレイと同じくファイル一覧へキーボードフォーカスを戻す。
- **[R-2424] 結果が新しく届くたびに、選択位置を先頭に戻す。** 入力を変えたときも先頭に戻す。

## 5. 検索の範囲と照合

- **[R-2430] 検索はバックエンドのコマンド `fs_fuzzy_search(path, query, max_results, show_hidden)` で行う(`app/src-tauri/src/fs/commands.rs`、本体は `app/src-tauri/src/fs/fuzzy.rs` の `search_files`)。** 画面は `path` に検索の起点、`query` に入力欄の文字列、`max_results` に 100、`show_hidden` に開いた時点のファイル一覧の隠しファイルの表示の設定(SPEC-0300-0009 R-74)を渡す(`shared/ipc/fuzzy.ts` の `fsFuzzySearch`)。
- **[R-2431] 入力欄の文字列が変わったら、最後の変更から 150ms 入力が止まった時点で新しい検索を1回始める(続けて打った間は検索しない)。** 開いた直後は空の入力ですぐに検索する(R-2403)。
- **[R-2432] 検索の範囲と照合は次のとおりとする。**
  1. 検索の起点の配下を、浅い順(フォルダーごとに中身を読み、見つけたフォルダーを後で読む順)にたどる。検索の起点そのものは結果に含めない。
  2. 名前が次のいずれか(英字の大小を区別しない)に当たるフォルダーは、結果に含めず、中もたどらない: `.git`、`.hg`、`.svn`、`node_modules`、`target`、`dist`、`build`、`.cache`、`.vscode`、`.idea`、`.next`、`.nuxt`、`venv`、`.venv`、`__pycache__`。
  3. 名前が `.` で始まる項目(ファイルとフォルダー)は、ファイル一覧と同じく隠しファイルとして扱い(SPEC-0300-0009 R-74)、`show_hidden` が偽なら結果に含めず、フォルダーの中もたどらない。`show_hidden` が真なら他の項目と同じに扱う(2 のフォルダーは除く)。
  4. 項目の種類はフォルダーの列挙の結果の種類で決め、リンクをたどらない。フォルダーとして返らない項目(シンボリックリンク・ジャンクション等)は、ファイルの項目として扱い、中をたどらない。
  5. 読めないフォルダー・読めない項目は、知らせずに飛ばす。
  6. 調べる項目の数は、読んだ項目の数が 40,000 件に達した時点で打ち切る(評価するのは 39,999 件まで)。打ち切ったことは知らせない。
  7. 入力の前後の空白を除いた文字列(以下「語」)が空のときは、調べたすべての項目を結果とし、点数を `1000 − 50 × (相対パスの中の / の数) − (相対パスのバイト数)` とする(浅く短いものが先)。
  8. 語が空でないときは、相対パスに語の文字が順に(間に他の文字を挟んでよく、先頭から貪欲に)すべて現れる項目だけを結果とする。語に大文字が1文字でもあれば大文字小文字を区別し、無ければ ASCII の英字の大小を区別せずに比べる(ASCII 以外の文字は常にそのまま比べる)。
  9. 8 の点数は、100 を基本とし、相対パス全体が語と(ASCII の大小を区別せずに)等しければ 1000 を加え、一致した文字ごとに次を加え、最後に `⌊相対パスの文字数 ÷ 2⌋` を引く: 直前の一致した文字と隣り合えば +25。位置が先頭なら +30、直前の文字が `/` / `\` なら +35、`_` / `-` / `.` なら +20、直前が小文字で自分が大文字なら +20(いずれか1つ)。相対パスの最後の `/` より後(名前の部分。`/` が無ければ全体)にあれば +15。
  10. 結果は、点数の高い順、同点なら相対パスのバイト数の短い順、さらに相対パスの文字列の順に並べ、先頭の `max_results` 件(画面からは 100 件)だけを返す。
- **[R-2433] 結果のフルパス(`path`)は Windows の形(区切り `\`。例 `C:\work\src\main.rs`)で返し、そのまま移動先に使える(SPEC-0300-0016 R-722-3 の絶対パス)。** 相対パス(`relativePath`、画面の表示と照合に使う)は区切りを `/` にした文字列で返す。一致した位置(`matchIndices`)は相対パスの中の UTF-16 の位置(JavaScript の文字列の位置)で返す。
- **[R-2434] 検索中の表示と、古い結果の扱い: 検索を始めると「検索中」とし、その検索より後に別の検索を始めた場合・画面を閉じた場合は、その検索の結果を捨てる(表示に使わない)。** バックエンドの検索は途中で止めない(終わるまで走り、結果は捨てられる)。

## 6. 選んだときの動き

- **[R-2440] 項目を選ぶ(Enter・行のクリック)と、まず画面を閉じ、次の移動を行う。** 移動は利用者による移動として行い(訪問履歴への記録・ツリーの追従・失敗の通知は SPEC-0300-0013 R-208 / R-238、SPEC-0300-0009 R-44 と同じ)、移動の後にファイル一覧へキーボードフォーカスを移す。
  1. フォルダー: そのフォルダーへ移動する。
  2. ファイル: そのファイルの親のフォルダー(パスの最後の区切りより前。ドライブの直下のファイルなら `C:\` のように区切りまで含むドライブのルート。区切りが無ければ現在のフォルダー)へ移動し、表示した一覧の中でそのファイルと同じパス(区切りの `\` / `/` を同一視して比べる)の項目をフォーカス行にする。選択は変えない(移動により選択は空になる。SPEC-0300-0009 R-72)。一覧にその項目が無ければ(隠しファイルの表示の設定で表示しない等)、フォーカス行は移動の結果のまま。
- **[R-2441] 選んだ結果の移動が失敗したときは、移動の失敗の通知(SPEC-0300-0013 R-238)に従い、表示中のフォルダーは変わらない。** 画面は閉じたままとする。

## 7. エラー

- **[R-2450] `fs_fuzzy_search` は、`path` が絶対パス(SPEC-0300-0016 R-722-3)でなければ、フォルダーを読まずに `FsListDirErrorDto` のコード `invalid_path` で拒否する(`fuzzy_search_checked`)。** 検索の起点の読み取りの失敗等、それ以外の失敗はエラーにせず、読めた範囲の結果(0件のこともある)を返す(R-2432 の 5)。
- **[R-2451] 画面は、検索のエラーを受け取ったとき(R-2450 を含む)、結果を空にして R-2413 の `一致するファイルはありません` を表示する。** 状態メッセージは出さない。

## 8. 既知の制限

- 検索はバックエンドで途中で止めない。入力が止まってから始める(R-2431)ため回数は少ないが、大きなフォルダーでは1回の検索が最大 40,000 件を読む(R-2432 の 6)。
