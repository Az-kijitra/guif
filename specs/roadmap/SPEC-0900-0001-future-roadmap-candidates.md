本仕様は「今回の新プロダクトに実装しないが、将来必要になる可能性が高い」と発注者が明言した機能を**記録のみ**を目的として残すものである。**要件でも実装計画でもない。** 本仕様に記載された機能を今回の開発スコープに含めてはならない(SPEC-0100-0005 R-03, R-04)。

## 2. ロードマップ候補

### 2.1 Git連携パネル(ビルトイン、Ctrl+G)

- 位置づけ: 今回スコープ外。将来のロードマップ候補として記録する。
- 既存の状況: `main` ブランチには存在せず、未マージの `new-feature-experiment` ブランチにのみ存在する実験的機能。既存調査 1.2-1 によれば `GitPanel.svelte`(938行)、`git_ops.rs`(318行)、`git_cmds.rs`、`utils/tauri_git.ts` 等で構成され、`std::process::Command` によるgit CLIのサブプロセス実行として実装されていた(git2 等のRustライブラリ依存はなし)。
- 要件・実装方針は現時点で一切決定しない。将来着手する際は、改めて要件抽出から実施すること。

### 2.2 WinMerge連携(外部差分ツール起動、Ctrl+W)

- 位置づけ: 今回スコープ外。将来のロードマップ候補として記録する。
- 既存の状況: `main` ブランチには存在せず、`new-feature-experiment` ブランチにのみ存在。既存調査 1.2-2 によれば `winmerge_ops.rs`(88行)、`winmerge_cmds.rs`、`utils/tauri_winmerge.ts` で構成され、デュアルペイン時のクロスペイン比較として配線されていた。
- 要件・実装方針は現時点で一切決定しない。
- 注記: 既存実装はデュアルペイン(スコープ外かつロードマップ対象外)を前提とした配線であったため、将来の実現方式は既存実装と同一にはならない可能性がある。

### 2.3 パスワード付き(暗号化)ZIP の作成・展開【2026-09-27 追補】

- 位置づけ: 今回(MVP)スコープ外。将来のロードマップ候補として記録する(**要件ではなく候補**)。MVP では暗号化エントリを含む ZIP を `zip_encrypted` として拒否し、パスワード付き ZIP を作成しない(SPEC-0300-0014 R-327-5 / R-362 #3 / R-390)。
- 既存の状況: `main` ブランチには存在する。作成時は AES-256 で暗号化し(ZipCrypto では作らない)、展開時はパスワードで復号、試行回数3回の制限はフロントのみ。誤パスワードの検出はエラー翻訳による置換で到達不能になる不具合があった(main調査(Phase5)`specs/_drafts/existing-main-20260926-phase5-zip-detail.md` §1〜§3, §8 #2)。
- 要件・実装方針は現時点で一切決定しない。将来着手する際に再検討すべき論点の記録のみ: 暗号方式(AES-256 は Windows 標準エクスプローラーで開けない)、誤パスワード検出の修正、試行回数の制限、パスワードのログ非出力。
- 将来対応する場合も、MVP の安全性要件(SPEC-0300-0014 §6)と `zip_encrypted` の扱いを改めて見直すこと。

### 2.4 内蔵ビューア の拡張機能【2026-09-27 追補】

- 位置づけ: 今回(MVP、Phase 6)スコープ外。将来のロードマップ候補として記録する(**要件ではなく候補**)。MVP のビューアの範囲は SPEC-0300-0015 が規定し、同 R-530 が MVP 外の一覧である。
- 候補(発注者確定 2026-09-27 で将来フェーズとして記録するとされたもの): 大容量テキストの仮想スクロール、画像のプリフェッチ・多層キャッシュ・PNG 正規化、シンタックスハイライト、ビューア内検索(Ctrl+F)。
- その他の候補(SPEC-0300-0015 R-530): ファイル選択(Ctrl+O)、文字コードの手動切替、折り返しの切替、GIF / WebP / SVG 等の表示、ヘックスダンプ、EXIF・回転、ズーム倍率の永続化、ファイル変更の追従、ビューア → ファイラーの連動、ビューア内キーのキーマップ化・テーマ連動・i18n。
  - **【2026-10-04 追補・発注者決定 2026-10-04(S-2)、同日 発注者承認】このうち「テーマ連動」は実装済み(Phase 12。ビューアはメイン画面と同じテーマに従う。SPEC-0300-0015 第5版 R-511、SPEC-0300-0017 第5版 R-913 系)。記録として候補の文言は残す。** ビューア内キーのキーマップ化・i18n は候補のまま。
  - **【2026-10-10 追補・2026-10-10 発注者承認。発注者決定 2026-10-09(ISS-0211)】上の候補のうち「シンタックスハイライト」は Phase 13 で実装する(テキスト表示と Markdown の Text モード。SPEC-0300-0015 第8版 §8.1)。記録として候補の文言は残す。** Markdown の HTML 表示のコードブロックの色分け(SPEC-0300-0015 第8版【確定 T-20】により今回は適用しない)と、`main` の8言語(同 R-466-2、【確定 T-16】)以外の言語の色分けは候補とする。仮想スクロール・画像のキャッシュ・ビューア内検索は候補のまま。
- 既存の状況: 仮想スクロール・画像キャッシュ・シンタックスハイライトは `main` に実装がある。ビューア内検索・Ctrl+O は `main` のマニュアルにのみ記載があり実装は無い(main調査(Phase6)`specs/_drafts/existing-main-20260927-phase6-viewer-detail.md` §2, §6, §8)。
- 要件・実装方針は現時点で一切決定しない。右クリックコンテキストメニューからの「開く」は候補ではなく後続フェーズで実装する事項であり(SPEC-0300-0015 R-401-1)、本節には含めない。

### 2.5 画面の文言の英語対応(言語の切替)【2026-10-08 追補・2026-10-09 発注者承認】

> 本節は 2026-10-08 に DRAFT として起票し、2026-10-09 の発注者承認(SPEC-0300-0019 第1版と同じ承認)で確定した。
