# Spec ID 台帳 (`guif`)

階層構造で仕様を管理する。Spec IDは `SPEC-<領域番号>-<連番>` 形式(例: `SPEC-0100-0001`)。

## 領域一覧

| 領域番号 | 領域名 | ディレクトリ | 説明 |
|---|---|---|---|
| 0100 | プロダクト方針 | `specs/product/` | 目的・基本コンセプト・スコープ境界・製品名 |
| 0200 | アーキテクチャ・技術基盤 | `specs/architecture/` | 技術スタック(Tauri 2 + Rust + Svelte 5)、プロセス間通信 |
| 0300 | コア機能 | `specs/features/` | ファイル一覧・ツリー・キーマップ・ファイル操作・ZIP・検索・ビューア・tuif-look |
| 0400 | 品質・テスト | `specs/quality/` | テスト戦略(単体テスト、E2Eテスト)、品質基準 |
| 0500 | ドキュメント | `specs/documentation/` | README / ユーザーマニュアル / 整合性要件 |
| 0600 | 配布・リリース | `specs/release/` | NSIS インストーラー・配布構成 |
